🏁 SE PB Report Import

Cross-check PBs against your club's official Swim England Top Times report(s). This never creates, removes, or hides a swimmer, and never touches Squad - it only adds or reconciles PB times. Each import brings in whichever times the SE report currently lists as official - it can't see, and so can't bring in, a time that's since been beaten and dropped off the report.

⚙️ Settings

Stored in your browser only - never embedded in the dashboard file. The URL and token are the same for everyone (one shared ACCESS_TOKEN is set in the Apps Script project), so each coach just needs to paste the same two values into their own browser once. This isn't per-coach login - anyone with the token has the same access - it just keeps the token out of the public HTML file.

🔄 Sync from Google Sheets

Fetches swimmer profiles and PBs from the Google Sheet. Credentials are read from Settings and stored only in this browser - not in the file.

⚠️ No Apps Script URL configured yet - paste it below, or set it once in ⚙️ Settings.
This only affects swimmers who can't be found in the Sheet. Swimmers are matched by name and date of birth, so a spelling change in either place makes a swimmer look missing. It is not about PBs: for every swimmer who is in the Sheet, their manually added and SE-imported PBs are always kept, and the Sheet's times are simply added alongside.
Keep - missing swimmers and their PBs are left untouched. Hide - kept with all their PBs, but hidden from the tabs. Remove - the swimmer and all their PBs (manual and SE-imported too) are deleted - you'll be shown a list and asked to confirm first. Download a backup if you're unsure.
